Why Cloud-Based Notes Sharing?

☁️

Amazon S3 Storage

Study materials such as PDFs, DOCX, and PPT files are durably stored in Amazon Simple Storage Service.

🗄️

MySQL / RDS Metadata

Fast indexing of student names, course subjects, and timestamps stored securely in an isolated database tier.

🔒

Secure Cloud Access

Private subnets and least-privilege IAM roles ensure that credentials and files are never exposed publicly.
